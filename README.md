# CSE 306

Coursework repository for CSE 306 Computer Architecture sessional assignments.

## Repository Contents

- `CSE 306 Assignment 1.pdf` - assignment specification for the simplified ALU design.
- `A2_Group3.circ` - Logisim circuit for the ALU assignment.
- `A2_Group3_Report.pdf` - group report for the ALU assignment.
- `ALU Design.pptx` - lecture slides covering ALU design, adders, logic operations, and status flags.
- `CSE 306 Quiz - July 2022.pdf` - quiz question paper.
- `Offline_02/` - floating-point adder assignment materials.
- `Offline_03/` - simplified processor/MIPS-style implementation materials.

## Offline 02

Floating-point adder assignment.

- `CSE 306 Assignment 2.pdf` - assignment specification.
- `A2_Group3.circ` - Logisim implementation of the floating-point adder.
- `A2_Group3_Report.pdf` - group report.

The circuit includes blocks for exponent comparison, significand comparison, shifting and addition, normalization, rounding, underflow handling, zero handling, and sign-bit calculation.

## Offline 03

Processor implementation assignment.

- `Assignment 3.pdf` - assignment specification.
- `A2_Group3_Report.pdf` - group report.
- `A2_Group3_Submission.zip` - submission archive containing source code, simulation files, and generated build outputs.

The submission archive includes AVR C/C++ modules for:

- ALU
- Control unit
- Data memory
- Instruction memory
- Register file
- Assembler/instruction conversion utility

## Tools and Formats

- `.circ` files are Logisim circuit files.
- `.pdsprj` files are Proteus simulation project files.
- `.cpp` files in the submission archive target AVR-style microcontroller modules.
- `.pdf` files contain assignment statements, quiz material, and reports.
- `.pptx` contains supporting lecture material.

## Notes

This repository mainly stores assignment artifacts and reports. Most generated build files are kept inside the original submission archive for completeness.
